# Shoal brand assets

This directory stores design assets for collaborators. It is outside `public/` and
is not part of the app interface, favicon, or page metadata.

## Clay shell icon

`shoal-shell-icon.png` is a generated claymation scallop-shell app icon concept.
Generated with built-in imagegen. The PNG is 1254 × 1254 pixels with an opaque
off-white background. The exact final prompt is stored in
`shoal-shell-icon.prompt.txt`; the full prompt history is in
`shoal-shell-icon.prompts.json`.

**User instruction:** keep this asset stored for other agents. Do not add it to the
site or use it as the app icon until the user explicitly requests that integration.
