# Shoal sea-animal slide icons

Four individual clay-style characters based on the existing Shoal avatar artwork: Octopus, Seal, Sea Turtle, and Seahorse.

Each 1254 x 1254 PNG has a verified alpha background and can be placed directly on a slide. Keep the PNG format to retain transparency. These are standalone assets; the app avatar sprite sheets are unchanged.

Generated with the built-in image_gen editing tool from the awake expression in each original sprite sheet. Exact prompts are stored beside the PNGs. Pufferfish attempts produced an opaque checkerboard and were excluded from the downloadable pack.
